# APA 7th Edition Writing Skill

Follow these rules when writing or reviewing academic content in APA 7th Edition format.

## Paper Format

- **Font**: 12pt Times New Roman, 11pt Calibri, 11pt Arial, or 11pt Georgia (one font throughout)
- **Spacing**: Double-space everything. No extra space before/after headings or between paragraphs
- **Margins**: 1 inch (2.54 cm) on all sides
- **Alignment**: Left-align. Do not use full justification
- **Paragraph indent**: 0.5 inch first-line indent
- **Page numbers**: Flush right in header of every page
- **One space** after sentence-ending punctuation
- **Serial comma** (Oxford comma) before final element in lists of 3+

## Title Page (Student Paper)

Center all elements, double-spaced, in upper half of page:
1. **Title**: Bold, Title Case (capitalize major words of 4+ letters, plus linking verbs Is/Are/Be)
2. **Author name**: Full name (First Middle. Last)
3. **Affiliation**: Department, University
4. **Course**: Number and name per syllabus
5. **Instructor**: Title and name per syllabus
6. **Due date**: Month Day, Year (e.g., May 4, 2020) or Day Month Year (e.g., 4 May 2020)

## Page Order

Start each on a new page: Title Page → Abstract (if needed) → Text → References → Footnotes (if needed) → Tables (if needed) → Figures (if needed) → Appendices (if needed)

## Heading Levels

| Level | Format |
|-------|--------|
| 1 | **Centered, Bold, Title Case** |
| 2 | **Left-Aligned, Bold, Title Case** |
| 3 | **Left-Aligned, Bold Italic, Title Case** |
| 4 | **Indented, Bold, Title Case, Period.** Text follows on same line |
| 5 | **Indented, Bold Italic, Title Case, Period.** Text follows on same line |

Repeat the paper title (centered, bold) on first text page as introduction heading. Do not use "Introduction" as a heading. Use Level 2 headings for subsections in the introduction.

## In-Text Citations

| Situation | Format |
|-----------|--------|
| One author | (Author, Year) or Author (Year) |
| Two authors | (Author & Author, Year) or Author and Author (Year) |
| 3+ authors | (FirstAuthor et al., Year) or FirstAuthor et al. (Year) |
| No author | Use title first 2-3 words + year; article titles in quotes, book/report titles in italics |
| Group author | Full name [abbreviation] on first use, abbreviation thereafter |
| Direct quote (<40 words) | Double quotes, include page: (Author, Year, p. X) or (para. X) |
| Block quote (40+ words) | Indent 0.5 inch from left margin, no quotes, citation after final punctuation |
| Multiple works | Alphabetical order, semicolons between citations |
| Same author, multiple years | Chronological, commas: (Coutlee, 2019, 2020) |
| Same author, same year | Letter suffixes: (Shapiro, 2003a, 2003b) |
| Personal communication | In-text only, not in References: (R. Takaki, personal communication, October 17, 2001) |
| Secondary source | (cited in Swenson, 2000) |

## Reference List

### Format Rules
- Start on new page after text, heading "References" centered and bold
- Double-space entire list (within and between entries)
- **Hanging indent**: first line flush left, subsequent lines 0.5 inch
- **Alphabetical** by first author surname
- Every reference must have a corresponding in-text citation

### Author Format
- Surname first, initials: Author, A. A.
- Comma after each author (even with two), ampersand (&) before last author
- Up to **20 authors** listed; with 21+, list first 19 + "…" + last author
- Group authors: write out full name

### Title Format
- **Sentence case**: capitalize first word, subtitle, and proper nouns only
- **Standalone works** (books, reports, dissertations): *italicize title*
- **Works that are part of a larger whole** (journal articles, book chapters): do not italicize

### DOI / URL
- Use DOI if available; use URL if no DOI (only for freely accessible online works, not from databases)
- Present as live hyperlinks (https://...), no "Retrieved from"
- No period after DOI/URL
- Do not include database information for academic research databases

### Reference Templates

**Journal article**:
```
Author, A. A. (Year). Title of article. *Title of Journal, Volume*(Issue), Page-Page. https://doi.org/xxxx
```

**Authored book**:
```
Author, A. A. (Year). *Title of work: Subtitle*. Publisher. DOI
```

**Edited book**:
```
Editor, A. A. (Ed.). (Year). *Title*. Publisher.
```

**Book chapter**:
```
Author, A. A. (Year). Chapter title. In B. B. Editor (Ed.), *Book title* (pp. xx-xx). Publisher.
```

**Doctoral dissertation**:
```
Author, A. A. (Year). *Title* [Doctoral dissertation, University]. Database. URL
```

**Conference presentation**:
```
Author, A. A. (Year, Month). *Title* [Conference presentation]. Conference Name, Location. DOI/URL
```

**Webpage**:
```
Author, A. A. (Year). *Title*. Site Name. URL
```

**Preprint**:
```
Author, A. A. (Year). *Title*. Repository. DOI
```

**Data set**:
```
Author, A. A. (Year). *Title* [Data set]. Publisher. DOI
```

**Software**:
```
Author, A. A. (Year). *Title* (Version X.X) [Computer software]. Publisher. DOI
```

## Writing Style

- **Active voice** preferred over passive. Use first person (I, we) to describe own work
- **Verb tense**: Introduction (present/present perfect), Method (past), Results (past), Discussion (present)
- **Conciseness**: eliminate wordiness, redundancy, jargon, contractions, colloquialisms
- Use varied sentence length; avoid both very short and very long sentences
- No anthropomorphism (do not attribute human actions to inanimate objects)

### Numbers
- Words for 0-9, numerals for 10+
- Always use numerals for: statistics, measurements, fractions, decimals, ratios, percentages, time, dates, ages, scores, money

### Statistics
- In narrative: "the means were" not "the Ms were"
- In parentheses: (M = 6.62) not (mean = 6.62)
- Italicize statistical symbols: *M*, *SD*, *t*, *F*, *p*, *r*, *R*², *α*, *η*²

## Bias-Free Language
- Use inclusive language for age, disability, gender, race/ethnicity, sexual orientation, socioeconomic status
- Use singular "they" for unknown/irrelevant gender
- Avoid stereotypes and prejudicial language

## Tables
- Number sequentially (Table 1, Table 2...), bold
- Title in italics, Title Case, on line below number
- Three-line table format (top, header, bottom borders only)
- Notes: general, specific, probability — each on own line, double-spaced

## Figures
- Number sequentially (Figure 1, Figure 2...), bold
- Title on same line as number, italic, Title Case, period at end
- Sans serif font in image (8-14pt)
- Legend within borders if needed
- Clearly labeled axes with units
